Empty your phone in two steps.

This page runs entirely in your browser. Nothing is uploaded anywhere — it reads and writes files directly on this computer via the File System Access API. Needs desktop Chrome or Edge.

  1. Plug the phone in with USB, set it to File transfer, and drag Internal storage/DCIM (plus Pictures and Download if you want them) into a folder on this computer. Or, faster: adb pull /sdcard/DCIM ./phone-dump
  2. Pick that folder as the Source above, pick where the sorted library should live as the Destination, and hit Scan.

The scan reads EXIF dates, groups by month, isolates screenshots, WhatsApp images, videos and byte-identical duplicates, and pre-rejects the junk. You review, then it writes everything into YYYY/YYYY-MM/ folders.

Rejected files are never deleted — they go to _Rejected/ so you can check before emptying it. "Move" mode only removes a source file after the copy has been written and its size verified.

Keys: arrows move · K keep · D reject · Enter big view · A keep whole group · R reject whole group
